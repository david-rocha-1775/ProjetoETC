# Templates de Layout

Arquivos compartilhados de estrutura das views.

## Arquivos

- `header.php`: abre a página, carrega estrutura base e mensagens de retorno.
- `footer.php`: fecha a estrutura principal e encerra o HTML.

## Uso

- As views devem incluir `header.php` no início e `footer.php` no final.
- Este diretório deve conter apenas estrutura reutilizável, sem lógica de negócio.
